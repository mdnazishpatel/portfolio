## 🌑 CLASSIFIED BRIEFING

A dark, cinematic personal portfolio built with **Next.js**. No yellow, no blood-red. Just black, ash and white, in the spirit of Arkham-era noir. The whole site plays out across **five scenes of Gotham**, each section styled like a different piece of the Batman universe.

> *"Gotham doesn't need a resume. It needs proof."* 🦇

---

## 🚀 BOOT UP THE BATCOMPUTER

**1. Clone the repo**

```bash
git clone https://github.com/mdnazishpatel/portfolio.git
cd portfolio
```

**2. Install dependencies**

```bash
npm install
```

**3. Configure environment** *(only if you use env variables, e.g. your Formspree ID)*

```env
# .env.local
NEXT_PUBLIC_FORMSPREE_ID=your_form_id
```

**4. Launch**

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and the Batcomputer is online. 🦇

---

## 🛩️ DEPLOY TO GOTHAM

```bash
npm run build
npm start
```

Or push to GitHub and import the repo on [Vercel](https://vercel.com/new). Every push deploys automatically.

## 🔧 MODIFY THE SUIT
